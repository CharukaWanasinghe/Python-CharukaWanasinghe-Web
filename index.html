1. Python කියන්නේ මොකක්ද?

Python කියන්නේ 1991 දී Guido van Rossum විසින් නිර්මාණය කළ high-level programming language එකක්. අපි කතා කරන භාෂාවට ළඟ, කියවන්න ලේසි syntax එකක් තියෙන නිසා මුල් වරට programming ඉගෙන ගන්නන්ට හොඳම තේරීමයි.

Python භාවිතා වෙන තැන්

  • Web development – Django, Flask
  • Data Science / AI / Machine Learning – NumPy, Pandas, TensorFlow
  • Automation – නිතර කරන වැඩ script එකකින් කරවා ගන්න
  • Games, Desktop apps, Cybersecurity

ඇයි Python?

  • Interpreted: code එක පේළියෙන් පේළිය run වෙනවා. compile කරන්න ඕනේ නෑ.
  • Dynamically typed: variable එකට type එක කලින් කියන්න ඕනේ නෑ.
  • Indentation: අනිත් භාෂාවල { } වෙනුවට Python වල space (ඉඩ) වලින් code block එක හඳුන්වනවා.

4. Variables

Variable එකක් කියන්නේ දත්තයක් තබා ගන්න නම දැමූ පෙට්ටියක්. = වලින් අගය දෙනවා.

6. Operators

print(7 // 2)   # 3    (පූර්ණ බෙදීම)

11. Functions

Function එකක් කියන්නේ නැවත නැවත භාවිතා කළ හැකි code කොටසක්. def වලින් හදනවා.

def greet(name, msg="ආයුබෝවන්"):
    return f"{msg} {name}!"

print(greet("සුනිල්"))
print(greet("සුනිල්", "සුභ උදෑසනක්"))

def area(w, h):
    return w * h

print(area(4, 5))   # 20

square = lambda x: x * x   # lambda (කෙටි function)
print(square(6))           # 36
  • Parameter: function එක ඇතුළේ ඉල්ලන අගයන්
  • return: ප්‍රතිඵලය ආපසු දෙනවා (print එකට වඩා වෙනස්)
  • Default value: msg="ආයුබෝවන්"

12. Classes සහ Objects (OOP)

Class එක කියන්නේ බ්ලූප්‍රින්ට් එකක් (ගෙයක සැලැස්ම වගේ); Object එක කියන්නේ ඒකෙන් හදන ඇත්ත ගෙය.

class Student:
    def __init__(self, name, marks):   # constructor
        self.name = name
        self.marks = marks

    def grade(self):
        return "Pass" if self.marks >= 50 else "Fail"

s1 = Student("අමාලි", 82)
s2 = Student("රවී", 40)
print(s1.name, s1.grade())   # අමාලි Pass
print(s2.name, s2.grade())   # රවී Fail

class Teacher(Student):      # Inheritance (උරුමය)
    pass

self කියන්නේ දැනට පවතින object එකම. __init__ object එක හදද්දී ස්වයංක්‍රීයව run වෙනවා.

13. Error Handling සහ Files

    print("බිංදුවෙන් බෙදන්න බෑ!")
finally:
    print("අවසානයි")
